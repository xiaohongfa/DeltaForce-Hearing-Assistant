# 三角洲行动 · 听障人声音雷达辅助器 (MVP)
感觉不如我耳朵有用








专门针对听障玩家设计的战术射击游戏声源可视化雷达。
通过对系统音频进行低延迟数字信号处理（DSP），在桌面上以科幻半透明战术雷达形式实时呈现**声音的方位（Direction）**与**声音大小（Magnitude/Distance）**。

---

## 核心特性与优势

1. **绝对账号安全（100% 外部处理）**：
   - **零内存读写、零 DLL 注入、零游戏进程 Hook**。
   - 完全基于 Windows 官方标准 API（WASAPI Loopback 扬声器回环）录制系统输出的声音流。腾讯 ACE 等反作弊系统无法亦无权判定为作弊。
2. **超低计算延迟（< 0.1ms）**：
   - 摒弃了会引入 50~100ms 滞后且浪费算力的深度学习，全链路采用高性能数学向量加权与 IIR 带通滤波，单帧处理耗时仅 **0.071 毫秒**。
3. **支持 360° 全向环绕与双耳立体声**：
   - 当 Windows/游戏开启 7.1/5.1 环绕声时，支持 360° 全向空间解算。
   - 当使用普通双声道立体声耳机时，支持双耳强度差（ILD）方位指示。
4. **脚步声频段硬件级聚焦**：
   - 内置 4 阶巴特沃斯带通滤波器（`150Hz ~ 1800Hz`），可一键过滤低频爆炸轰鸣与环境高频风噪，突出脚步与换弹声。
5. **无需启动游戏的离线模拟模式（Mock Mode）**：
   - 内置 360° 空间声源发生器，在不打开任何游戏的情况下即可自测雷达旋转、光斑扩散与滤波效果。

## 界面交互与操作说明

* **拖拽定位**：按住标题栏或雷达表盘任意位置，即可在桌面上拖动雷达至任意满意的位置（如小地图侧边或屏幕准心上方）。
* **始终置顶（Always-on-Top）**：雷达自动悬浮于所有游戏无边框/窗口化屏幕之上。
* **离线模拟 / 系统回环切换**：
  - 点击 `离线模拟`：雷达将接收内置生成的 360° 旋转虚拟脚步声，便于调节灵敏度与观赏效果。
  - 点击 `系统回环`：开始监听 Windows 当前正在播放的声音（游戏、音乐或测试视频）。
* **灵敏度调节（Gain）**：针对不同耳机音量调整雷达反应幅度。
* **降噪门限（Squelch Gate）**：低于该分贝值（默认 -50dB）的环境轻微杂音不会唤醒雷达，避免视觉干扰。
* **脚步频段增强开关**：勾选后开启带通滤波，抑制环境轰鸣。

## 项目代码结构

* [`audio_core.py`](audio_core.py)：WASAPI 音频捕获、7.1/5.1 矢量合成、立体声 ILD 解算、巴特沃斯滤波器及模拟发生器。
* [`radar_ui.py`](radar_ui.py)：基于原生 Tkinter 的半透明军规战术雷达悬浮窗，包含余辉渐隐（Phosphor decay）、光斑热力渲染及控件。
* [`main.py`](main.py)：控制器主入口，负责在音频 DSP 线程与 UI 主线程间进行零延迟队列调度与模式切换。
* [`test_radar.py`](test_radar.py)：方位角误差校验、立体声 ILD 验证、频段滤除测试及延迟基准测试。
